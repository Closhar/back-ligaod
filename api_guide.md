# Полное руководство по работе с API Sportrep

## Базовый URL
```
https://p.sportrep.ru/api/v1
```

## Общая информация
API предоставляет доступ к данным о спортивных мероприятиях, командах, аренах и других сущностях системы. Все ответы возвращаются в формате JSON.

> **Важно**: Для получения корректных результатов рекомендуется использовать полные URL-адреса, указанные в этом руководстве. Это обеспечит правильную маршрутизацию запросов и получение актуальных данных.

## Получение ID сущностей

### Поиск ID видов спорта
```
GET https://p.sportrep.ru/api/v1/sports
```
Пример промта: `Покажи все виды спорта`
- Возвращает список всех видов спорта с их ID
- Можно фильтровать по названию: `Покажи вид спорта "футбол"`

## Эндпоинты API

### Мероприятия (Events)
- **Получить список мероприятий**
  - GET `https://p.sportrep.ru/api/v1/events`
  - **Параметры запроса:**
    - `per_page` (integer, default: 10) - количество записей на странице
    - `page` (integer, default: 1) - номер страницы
    - `get_events` (integer) - ограничение на количество возвращаемых записей
    - `date_from` (date) - фильтр по начальной дате
    - `date_to` (date) - фильтр по конечной дате
    - `sport` (string) - фильтр по slug вида спорта
    - `sport_id` (integer) - фильтр по ID вида спорта
    - `club` (string) - фильтр по slug клуба
    - `club_id` (integer) - фильтр по ID клуба
    - `arena` (string) - фильтр по slug арены
    - `arena_id` (integer) - фильтр по ID арены
    - `competition_id` (integer) - фильтр по ID соревнования
    - `gender_id` (integer) - фильтр по ID пола
    - `show` (integer) - фильтр по временному периоду:
      - 1: date_from >= сегодня (по умолчанию)
      - 2: date_from <= сегодня
      - 3: date_from = сегодня
      - 4: без ограничений по date_from
    - `q` (string) - поисковый запрос
    - `region_id` (integer) - фильтр по ID региона
    - `is_active` (boolean) - фильтр по активности
    - `show_native` (boolean) - показывать события с командой из региона
    - `series_id` (integer) - фильтр по ID серии
    - `sort_field` (string, default: 'date_from') - поле для сортировки
    - `sort_direction` (string, default: 'asc') - направление сортировки

- **Получить мероприятие по ID**
  - GET `https://p.sportrep.ru/api/v1/events/{id}`

## Примеры промтов для поиска

### Поиск мероприятий

1. **Поиск по дате:**
```
Найди все мероприятия с {дата} по {дата}
```
Пример: `Найди все мероприятия с 2024-03-01 по 2024-03-31`

2. **Поиск по виду спорта:**
```
Покажи все мероприятия по {название вида спорта}
```
Пример: `Покажи все мероприятия по футболу`

3. **Поиск по команде:**
```
Найди все матчи команды {название команды}
```
Пример: `Найди все матчи команды Спартак`

4. **Поиск по арене:**
```
Покажи все мероприятия на {название арены}
```
Пример: `Покажи все мероприятия на Лужники`

5. **Поиск по региону:**
```
Найди все мероприятия в регионе {название региона}
```
Пример: `Найди все мероприятия в регионе Москва`

### Сложные запросы

1. **Поиск всех футбольных матчей в Москве на следующей неделе:**
```
Найди все футбольные матчи в Москве с {дата начала недели} по {дата конца недели}
```

2. **Поиск всех соревнований по зимним видам спорта:**
```
Покажи все соревнования по зимним видам спорта в {регион}
```

3. **Поиск всех мероприятий с участием конкретной команды:**
```
Найди все матчи команды {название команды} с {дата} по {дата}
```

## Работа с ID сущностей

### Примеры промтов для получения ID

1. **Получение ID вида спорта:**
```
Покажи ID вида спорта "футбол"
```
или
```
Найди вид спорта "футбол" и покажи его ID
```

2. **Получение ID команды:**
```
Покажи ID команды "Спартак"
```
или
```
Найди команду "Спартак" в Москве и покажи её ID
```

3. **Получение ID арены:**
```
Покажи ID арены "Лужники"
```
или
```
Найди арену "Лужники" в Москве и покажи её ID
```

4. **Получение ID соревнования:**
```
Покажи ID соревнования "Чемпионат России по футболу"
```
или
```
Найди соревнование "Чемпионат России" по футболу и покажи его ID
```

### Использование ID в запросах

После получения ID сущности, его можно использовать в запросах:

1. **Поиск мероприятий по ID вида спорта:**
```
Найди все мероприятия с sport_id={id}
```

2. **Поиск мероприятий по ID команды:**
```
Найди все мероприятия с club_id={id}
```

3. **Поиск мероприятий по ID арены:**
```
Найди все мероприятия с arena_id={id}
```

## Примечания
- Все даты указываются в формате YYYY-MM-DD
- Для поиска по названиям можно использовать как полные названия, так и частичные совпадения
- При поиске по нескольким параметрам, они комбинируются через логическое И
- Для получения более точных результатов рекомендуется использовать ID сущностей вместо их названий
- Все запросы должны содержать заголовок `Accept: application/json`
- При необходимости аутентификации, используйте токен в заголовке `Authorization: Bearer {token}`
