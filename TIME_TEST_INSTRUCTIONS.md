# Инструкции для тестирования времени на сервере

## Проблема

Наступил следующий день 2 августа, но события "сегодня" не отображались, а события "завтра" показывали 2 августа, хотя надпись на сайте была 3 августа. Это рассинхронизация времени между фронтендом и бэкендом.

## Изменения, которые были внесены

### 1. Фронтенд (index.vue)

-   Добавлена функция `getLocalDate()` для получения даты в локальном формате
-   Добавлена функция `getUTCDate()` для получения даты в UTC формате
-   **ИСПРАВЛЕНО**: Теперь отображается локальное время, а для API запросов используется UTC
-   Используются UTC даты для API запросов и локальные даты для отображения

### 2. Бэкенд (ApiEventController.php)

-   Заменено `now()->toDateString()` на `\Carbon\Carbon::now('UTC')->toDateString()`
-   Это обеспечивает использование UTC времени для определения "сегодняшней даты"

### 3. Бэкенд (ApiCompetitionController.php)

-   Аналогичные изменения для консистентности

## Принцип работы

-   **Отображение**: Используется локальное время браузера (`toLocaleDateString('ru-RU')`)
-   **API запросы**: Используется UTC время для синхронизации с сервером
-   **Сервер**: Использует UTC время для всех операций с датами

## Тестирование

### 1. Запустите тест времени на сервере:

```bash
cd Laravel Backend
php test_time.php
```

### 2. Откройте тест времени в браузере:

Откройте файл `📁 Основной сайт/test-time.html` в браузере

### 3. Проверьте главную страницу:

-   Откройте главную страницу сайта
-   Проверьте, что события "сегодня" и "завтра" отображаются корректно
-   **ВАЖНО**: Убедитесь, что даты в заголовках показывают ваше локальное время (не UTC!)

## Ожидаемый результат

После внесения изменений:

-   События "сегодня" должны показывать события текущего дня
-   События "завтра" должны показывать события следующего дня
-   **Даты в заголовках должны показывать ваше локальное время**
-   Не должно быть рассинхронизации между фронтендом и бэкендом

## Если проблема остается

1. Проверьте часовой пояс сервера
2. Убедитесь, что все изменения применены
3. Очистите кэш браузера
4. Проверьте логи сервера на наличие ошибок
5. Убедитесь, что в заголовках отображается локальное время, а не UTC
