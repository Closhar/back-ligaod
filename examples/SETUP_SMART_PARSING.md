# Настройка системы умного парсинга

## Что нужно сделать

### 1. Запустить миграцию для новых полей

```bash
cd /var/www/p.sportrep.loc
php artisan migrate
```

Или вручную:
```bash
mysql -u username -p database_name < database/migrations/2025_01_15_000001_add_smart_parsing_fields_to_parser_fields_table.php
```

### 2. Обновить поля парсера с новой конфигурацией

```bash
mysql -u username -p database_name < examples/update_parser_fields_smart_parsing.sql
```

### 3. Проверить настройки в админке

Откройте страницу редактирования шаблона парсера. Теперь для каждого поля доступны:

- **Контекст поиска** - строка, в которой искать данные
- **Поисковая фраза** - фраза, после которой находятся данные
- **Разделитель значений** - символ для разделения значений
- **Формат результата** - специальный тип обработки
- **Идентификация команд** - настройки для определения команд

## Примеры конфигурации

### Поле "Броски" (статистика команд)
```
Контекст поиска: Статистика матча:
Поисковая фраза: Броски:
Разделитель значений: -
Формат результата: team_stats
```

**Результат**: `"59 | 50"`

### Поле "Результат матча"
```
Контекст поиска: матч завершен
Поисковая фраза: 4 – 3
Разделитель значений: –
Формат результата: match_result
```

**Результат**: `"4:3"`

### Поле "Команды"
```
Контекст поиска: Игра №
Поисковая фраза: :
Разделитель значений: -
Формат результата: team_names
Поисковая фраза для команд: Игра №
Разделитель команд: -
```

**Результат**: `"МХК Крылья Советов | ХК Капитан"`

### Поле "События игроков"
```
Контекст поиска: Изменение счета:
Поисковая фраза: Изменение счета:
Разделитель значений:  
Формат результата: player_events
Поисковая фраза для команд: Игра №
Разделитель команд: -
```

**Результат**: 
```json
[
  {
    "team": "МХК Крылья Советов",
    "player": "Башлыков Егор",
    "min": "51:20",
    "event": "Изменение счета: 4—3"
  }
]
```

## Тестирование

После настройки запустите тест:

```bash
php examples/test_parser_conditions.php
```

Ожидаемый результат:
- Вместо всего HTML в `value` будут конкретные данные
- Статистика команд: `"59 | 50"`
- Результат матча: `"4:3"`
- Названия команд: `"МХК Крылья Советов | ХК Капитан"`
- События игроков: структурированный JSON

## Преимущества новой системы

1. **Точность** - извлекает только нужные данные
2. **Гибкость** - поддерживает различные форматы
3. **Универсальность** - работает с разными сайтами
4. **Контекстность** - учитывает контекст поиска
5. **Автоматизация** - минимизирует ручную настройку

## Устранение проблем

### Если данные не извлекаются:
1. Проверьте правильность поисковых фраз
2. Убедитесь, что контекст найден на странице
3. Проверьте разделитель значений
4. Убедитесь, что формат результата выбран правильно

### Если команды не определяются:
1. Проверьте настройки идентификации команд
2. Убедитесь, что поисковая фраза для команд найдена
3. Проверьте разделитель команд

### Если события игроков пустые:
1. Проверьте поисковую фразу для событий
2. Убедитесь, что команды определены корректно
3. Проверьте формат времени в событиях

## Дальнейшее развитие

Система легко расширяется для новых типов данных:
- Добавьте новый `result_format`
- Создайте соответствующий метод извлечения
- Обновите админку для новых параметров
