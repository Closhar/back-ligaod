# Конфигурация умного парсинга для хоккейных матчей

## Обзор системы

Система умного парсинга позволяет извлекать конкретные данные по поисковым фразам вместо извлечения всего HTML. Поддерживаются различные форматы данных и специальная обработка для команд.

## Типы полей

### 1. Статистика команд (team_stats)

#### Поле "Броски"
```json
{
  "name": "shots",
  "selector": "body",
  "selector_type": "css",
  "target_table": "event_teams",
  "target_field": "shots",
  "result_format": "team_stats",
  "search_context": "Статистика матча:",
  "search_phrase": "Броски:",
  "value_separator": "-"
}
```

**Результат**: `"59 | 50"` (команда 1: 59, команда 2: 50)

#### Поле "Голы"
```json
{
  "name": "goals",
  "selector": "body",
  "selector_type": "css",
  "target_table": "event_teams",
  "target_field": "goals",
  "result_format": "team_stats",
  "search_context": "Статистика матча:",
  "search_phrase": "Голы:",
  "value_separator": "-"
}
```

**Результат**: `"4 | 3"` (команда 1: 4, команда 2: 3)

### 2. Результат матча (match_result)

#### Поле "Основной результат"
```json
{
  "name": "match_result",
  "selector": "body",
  "selector_type": "css",
  "target_table": "events",
  "target_field": "result",
  "result_format": "match_result",
  "search_context": "матч завершен",
  "search_phrase": "4 – 3",
  "value_separator": "–",
  "result_format": "4:3"
}
```

**Результат**: `"4:3"` (преобразование "4 – 3" в "4:3")

#### Поле "Дополнительный результат"
```json
{
  "name": "additional_result",
  "selector": "body",
  "selector_type": "css",
  "target_table": "events",
  "target_field": "dop_result",
  "result_format": "match_result",
  "search_context": "матч завершен",
  "search_phrase": "от",
  "value_separator": " ",
  "result_format": "буллиты"
}
```

**Результат**: `"буллиты"` (поиск после "от" до конца строки)

### 3. Названия команд (team_names)

#### Поле "Команды"
```json
{
  "name": "teams",
  "selector": "body",
  "selector_type": "css",
  "target_table": "events",
  "target_field": "teams",
  "result_format": "team_names",
  "search_context": "Игра №",
  "search_phrase": ":",
  "value_separator": "-",
  "team_identification": {
    "search_phrase": "Игра №",
    "team_separator": "-"
  }
}
```

**Результат**: `"МХК Крылья Советов | ХК Капитан"`

### 4. События игроков (player_events)

#### Поле "События игроков"
```json
{
  "name": "player_events",
  "selector": "body",
  "selector_type": "css",
  "target_table": "event_players",
  "target_field": "events",
  "result_format": "player_events",
  "search_context": "Изменение счета:",
  "search_phrase": "Изменение счета:",
  "value_separator": " ",
  "team_identification": {
    "search_phrase": "Игра №",
    "team_separator": "-"
  }
}
```

**Результат**: 
```json
[
  {
    "team": "МХК Крылья Советов",
    "player": "Башлыков Егор",
    "min": "51:20",
    "event": "Изменение счета: 4—3"
  }
]
```

## Алгоритм работы

### 1. Определение команд
1. Ищет строку с `search_phrase` (например, "Игра №")
2. После двоеточия `:` извлекает текст
3. Разделяет по `team_separator` (например, "-")
4. Получает команду 1 и команду 2

### 2. Извлечение статистики
1. Ищет `search_context` (например, "Статистика матча:")
2. В контексте ищет `search_phrase` (например, "Броски:")
3. Извлекает текст после фразы до разделителя
4. Разделяет по `value_separator` (например, "-")
5. Возвращает "значение1 | значение2"

### 3. Обработка результата матча
1. Ищет `search_context` (например, "матч завершен")
2. Ищет `search_phrase` (например, "4 – 3")
3. Применяет `result_format` для преобразования
4. Возвращает отформатированный результат

### 4. События игроков
1. Определяет команды
2. Ищет строки с `search_phrase` (например, "Изменение счета:")
3. Извлекает время, игрока и событие
4. Определяет команду по контексту
5. Возвращает структурированные данные

## Примеры использования

### Для страницы KHL:
- **Контекст**: "Статистика матча:"
- **Фразы**: "Броски:", "Голы:", "Вбрасывания:"
- **Разделитель**: "-"
- **Результат**: "59 | 50", "4 | 3", "23 | 23"

### Для результата матча:
- **Контекст**: "матч завершен"
- **Фраза**: "4 – 3"
- **Формат**: "4:3"
- **Результат**: "4:3"

### Для команд:
- **Контекст**: "Игра №"
- **Фраза**: ":"
- **Разделитель**: "-"
- **Результат**: "МХК Крылья Советов | ХК Капитан"

## Настройка через админку

1. Выберите тип поля
2. Укажите контекст поиска
3. Укажите поисковую фразу
4. Укажите разделитель значений
5. Выберите формат результата
6. Для команд укажите дополнительные параметры

## Преимущества

- **Точность**: Извлекает только нужные данные
- **Гибкость**: Поддерживает различные форматы
- **Универсальность**: Работает с разными сайтами
- **Контекстность**: Учитывает контекст поиска
- **Автоматизация**: Минимизирует ручную настройку
