# Чек-лист для проверки фронтенда

## Проблема
API работает корректно, но при добавлении команды через фронтенд возникает Internal Server Error.

## Диагностика фронтенда

### 1. Проверьте URL API в фронтенде
```javascript
// Проверьте в файлах фронтенда
// Должно быть:
const apiUrl = 'https://p.sportrep.ru/api/clubs'

// НЕ должно быть:
const apiUrl = 'http://localhost:8000/api/clubs'
const apiUrl = 'http://127.0.0.1:8000/api/clubs'
```

### 2. Проверьте данные, отправляемые с фронтенда
```javascript
// Проверьте, что отправляются правильные данные:
{
  title: 'Название клуба',
  title_short: 'КШ',
  city_id: 1,        // Должно быть число, НЕ строка
  sport_id: 1,       // Должно быть число, НЕ строка
  gender_id: 1,      // Должно быть число, НЕ строка
  is_alien: false    // Должно быть boolean, НЕ строка
}
```

### 3. Проверьте заголовки запроса
```javascript
// Убедитесь, что отправляются правильные заголовки:
headers: {
  'Content-Type': 'application/json',
  'Accept': 'application/json',
  'X-Requested-With': 'XMLHttpRequest'
}
```

### 4. Проверьте DevTools в браузере
1. Откройте DevTools (F12)
2. Перейдите на вкладку Network
3. Попробуйте добавить команду
4. Найдите запрос к `/api/clubs`
5. Проверьте:
   - Request URL
   - Request Method (должен быть POST)
   - Request Headers
   - Request Payload
   - Response Status
   - Response Headers

### 5. Проверьте консоль браузера
1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Попробуйте добавить команду
4. Ищите ошибки JavaScript

## Возможные проблемы

### 1. Проблема с URL
- Фронтенд использует неправильный URL API
- Проблема с доменами (crm.sporterp.ru vs p.sportrep.ru)

### 2. Проблема с данными
- Неправильный формат данных
- Отсутствующие обязательные поля
- Проблемы с кодировкой

### 3. Проблема с браузером
- Кеш браузера
- Cookies
- Сессии
- Расширения браузера

### 4. Проблема с сетью
- Проблемы с DNS
- Проблемы с прокси
- Проблемы с файрволом

## Решения

### 1. Очистите кеш браузера
- Ctrl+Shift+R (жесткая перезагрузка)
- Очистите кеш и cookies
- Попробуйте в режиме инкогнито

### 2. Проверьте конфигурацию фронтенда
- Убедитесь, что используется правильный URL API
- Проверьте переменные окружения
- Проверьте конфигурацию Nuxt.js

### 3. Проверьте данные
- Убедитесь, что все обязательные поля заполнены
- Проверьте типы данных (числа vs строки)
- Проверьте кодировку

### 4. Проверьте сеть
- Попробуйте с другого браузера
- Попробуйте с другого устройства
- Проверьте DNS настройки

## Отладочная информация

### Запустите тест на сервере:
```bash
php test_frontend_simulation.php
```

### Проверьте ответ сервера:
```bash
curl -X POST https://p.sportrep.ru/api/clubs \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -H "Origin: https://crm.sporterp.ru" \
  -H "Referer: https://crm.sporterp.ru/clubs" \
  -d '{"title":"Test Club","title_short":"TC","city_id":1,"sport_id":1,"gender_id":1,"is_alien":false}'
```

## Рекомендации

1. **Сравните запросы** - сравните запрос с фронтенда с успешным запросом из теста
2. **Проверьте заголовки** - убедитесь, что все заголовки правильные
3. **Проверьте данные** - убедитесь, что данные в правильном формате
4. **Проверьте логи** - ищите ошибки в логах сервера
5. **Тестируйте пошагово** - проверьте каждый этап запроса отдельно
