# API Документация Sportrep

## Базовый URL
```
https://p.sportrep.ru/api/v1
```

## Общая информация
API предоставляет доступ к данным о спортивных мероприятиях, командах, аренах и других сущностях системы. Все ответы возвращаются в формате JSON.

## Эндпоинты

### Пол (Genders)
- **Получить список полов**
  - GET `/genders`
  - Возвращает список всех доступных полов

- **Получить пол по ID**
  - GET `/genders/{id}`
  - Возвращает информацию о конкретном поле

### Мероприятия (Events)
- **Получить список мероприятий**
  - GET `/events`
  - Возвращает список всех мероприятий
  - **Параметры запроса:**
    - `per_page` (integer, default: 10) - количество записей на странице
    - `page` (integer, default: 1) - номер страницы
    - `get_events` (integer) - ограничение на количество возвращаемых записей (игнорирует пагинацию)
    - `date_from` (date) - фильтр по начальной дате
    - `date_to` (date) - фильтр по конечной дате
    - `sport` (string) - фильтр по slug вида спорта
    - `sport_id` (integer) - фильтр по ID вида спорта
    - `club` (string) - фильтр по slug клуба
    - `club_id` (integer) - фильтр по ID клуба
    - `arena` (string) - фильтр по slug арены
    - `arena_id` (integer) - фильтр по ID арены
    - `competition_id` (integer) - фильтр по ID соревнования
    - `gender_id` (integer) - фильтр по ID пола
    - `show` (integer) - фильтр по временному периоду:
      - 1: date_from >= сегодня (по умолчанию)
      - 2: date_from <= сегодня
      - 3: date_from = сегодня
      - 4: без ограничений по date_from
    - `q` (string) - поисковый запрос (ищет по title мероприятия, соревнования, клубов и городов)
    - `region_id` (integer) - фильтр по ID региона
    - `is_active` (boolean) - фильтр по активности мероприятия
    - `show_native` (boolean) - показывать события с командой из указанного региона независимо от региона события
    - `series_id` (integer) - фильтр по ID серии
    - `sort_field` (string, default: 'date_from') - поле для сортировки
    - `sort_direction` (string, default: 'asc') - направление сортировки ('asc' или 'desc')
  - **Возвращаемые поля:**
    - `id` - ID мероприятия
    - `title` - название мероприятия
    - `date_from` - дата начала
    - `date_to` - дата окончания
    - `result` - результат
    - `result_dop` - дополнительный результат
    - `image` - изображение
    - `competition_id` - ID соревнования
    - `arena_id` - ID арены
    - `club1_id` - ID первой команды
    - `club2_id` - ID второй команды
    - `region_id` - ID региона
    - `is_active` - активность
    - `event_name` - название события
    - `series_id` - ID серии
    - `series_count` - номер в серии
    - `about` - описание
    - `date_formatted` - отформатированная дата (DD.MM.YYYY)
    - `time` - время (HH:MM)
    - `my_region` - флаг принадлежности к региону (1 - да, 0 - нет)
    - **Связанные данные:**
      - `region` - информация о регионе
      - `streams` - стримы
      - `series` - информация о серии
      - `competition` - информация о соревновании
      - `club1` - информация о первой команде
      - `club2` - информация о второй команде
      - `arena` - информация об арене

- **Получить мероприятие по ID**
  - GET `/events/{id}`
  - Возвращает информацию о конкретном мероприятии
  - **Возвращаемые поля:**
    - Все поля из списка мероприятий
    - **Дополнительные связанные данные:**
      - `gallery` - галерея изображений
      - `articles` - связанные статьи

## Примеры использования

### Получение списка видов спорта
```bash
curl -X GET https://p.sportrep.ru/api/v1/sports
```

### Получение конкретного мероприятия
```bash
curl -X GET https://p.sportrep.ru/api/v1/events/123
```

## Примечания
- Все запросы должны содержать заголовок `Accept: application/json`
- При необходимости аутентификации, используйте токен в заголовке `Authorization: Bearer {token}`
- В случае ошибок API возвращает соответствующие HTTP-коды и сообщения об ошибках
