# Инструкция по работе с API Sportrep через промты

## Общие принципы работы с API

### Базовый URL
```
https://p.sportrep.ru/api/v1
```

### Формат запросов
Все запросы должны содержать заголовок:
```
Accept: application/json
```

## Примеры промтов для поиска информации

### Поиск мероприятий

1. **Поиск по дате:**
```
Найди все мероприятия с {дата} по {дата}
```
Пример: `Найди все мероприятия с 2024-03-01 по 2024-03-31`

2. **Поиск по виду спорта:**
```
Покажи все мероприятия по {название вида спорта}
```
Пример: `Покажи все мероприятия по футболу`

3. **Поиск по команде:**
```
Найди все матчи команды {название команды}
```
Пример: `Найди все матчи команды Спартак`

4. **Поиск по арене:**
```
Покажи все мероприятия на {название арены}
```
Пример: `Покажи все мероприятия на Лужники`

5. **Поиск по региону:**
```
Найди все мероприятия в регионе {название региона}
```
Пример: `Найди все мероприятия в регионе Москва`

6. **Комбинированный поиск:**
```
Найди все футбольные матчи в Москве с {дата} по {дата}
```
Пример: `Найди все футбольные матчи в Москве с 2024-03-01 по 2024-03-31`

### Поиск соревнований

1. **По виду спорта:**
```
Покажи все соревнования по {название вида спорта}
```
Пример: `Покажи все соревнования по хоккею`

2. **По полу:**
```
Найди все соревнования для {пол}
```
Пример: `Найди все соревнования для мужчин`

### Поиск арен

1. **По городу:**
```
Покажи все арены в городе {название города}
```
Пример: `Покажи все арены в городе Санкт-Петербург`

2. **По виду спорта:**
```
Найди все арены для {название вида спорта}
```
Пример: `Найди все арены для баскетбола`

### Поиск команд

1. **По виду спорта:**
```
Покажи все команды по {название вида спорта}
```
Пример: `Покажи все команды по волейболу`

2. **По городу:**
```
Найди все команды в городе {название города}
```
Пример: `Найди все команды в городе Казань`

### Поиск статей

1. **По теме:**
```
Найди статьи о {тема}
```
Пример: `Найди статьи о футбольных матчах`

2. **По дате:**
```
Покажи статьи за {период}
```
Пример: `Покажи статьи за март 2024`

## Параметры фильтрации

### Временные параметры
- `date_from` - начальная дата
- `date_to` - конечная дата
- `show` - период отображения:
  - 1: будущие мероприятия
  - 2: текущие мероприятия
  - 3: мероприятия на сегодня
  - 4: все мероприятия

### Фильтры по сущностям
- `sport` - вид спорта (slug)
- `sport_id` - ID вида спорта
- `club` - клуб (slug)
- `club_id` - ID клуба
- `arena` - арена (slug)
- `arena_id` - ID арены
- `competition_id` - ID соревнования
- `gender_id` - ID пола
- `region_id` - ID региона

### Дополнительные параметры
- `q` - поисковый запрос
- `is_active` - активность
- `show_native` - показывать события с командой из региона
- `series_id` - ID серии

### Сортировка
- `sort_field` - поле для сортировки
- `sort_direction` - направление сортировки (asc/desc)

## Примеры сложных запросов

1. **Поиск всех футбольных матчей в Москве на следующей неделе:**
```
Найди все футбольные матчи в Москве с {дата начала недели} по {дата конца недели}
```

2. **Поиск всех соревнований по зимним видам спорта:**
```
Покажи все соревнования по зимним видам спорта в {регион}
```

3. **Поиск всех мероприятий с участием конкретной команды:**
```
Найди все матчи команды {название команды} с {дата} по {дата}
```

4. **Поиск всех арен в определенном регионе:**
```
Покажи все спортивные арены в {регион} для {вид спорта}
```

## Примечания
- Все даты указываются в формате YYYY-MM-DD
- Для поиска по названиям можно использовать как полные названия, так и частичные совпадения
- При поиске по нескольким параметрам, они комбинируются через логическое И
- Для получения более точных результатов рекомендуется использовать ID сущностей вместо их названий
